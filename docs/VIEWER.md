# 神经记忆观察舱

```sh
python viewer/serve_neural.py
```

默认只绑定 127.0.0.1:8765。可通过 --port 更换端口，通过 --data 指定记忆副本。没有 --data 时在 viewer/runtime_data 中创建虚构演示；指定目录时不植入演示数据。

拖动旋转，滚轮缩放，点击事件查看内容；输入“加班”“海边”“咖啡”看召回路径。支持全屏、沉浸模式、手动写入、压制/恢复和确认删除。

Python 模式调用真实 recall_for_scheduler，路径返回自账本；删除沿用 forget 的完整保留正文匹配，可能同时清理包含相同正文的其他记录及队列。页面会重新拉取数据。它不是只读检查器，不要指向没有备份的唯一真实库。

直接打开 viewer/dist/index.html 使用 localStorage，前端轻量召回与 Python 算法不完全相同；浏览器演示保留率是示例值。两种模式清楚标识，彼此数据不自动同步。

浏览器导入接受 memories/episodes JSON 或事件数组，最多1000条、5MB，导入替换当前浏览器账本。Python 模式禁止浏览器导入覆盖 SQLite。导出仅含事件快照，不是含核心事实/队列/全部历史的完整数据库备份。

暗色神经元是装饰；亮色事件、线索和路径对应当前数据。页面字体可联网加载，离线会回退到系统字体。服务检查 Host/Origin，不开放跨来源读取；不提供登录、加密或公网部署授权。

测试包含本地 API 行为，不代表浏览器视觉、移动端或各设备效果均已人工验证。此仓库只提供可本地运行的源码，不附带任何个人已部署站点身份。
