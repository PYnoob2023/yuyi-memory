# 数据与公开发布边界

仓库只包含代码、文档和虚构示例。不要提交真实数据库、聊天、记忆导出、Cookie、API 密钥、私人备份、个人启动配置或观察报告。.gitignore 提供辅助排除，但不能替代提交前检查。

各模块使用不同数据库、每对用户/助手使用不同目录。来源编号应为不透明标识，不能把原文或秘密当作 ID。模块不提供文件加密、身份认证或多租户访问控制。

记忆使用来源门控但语义可能误判。情绪/自我的原始评估 context 不额外保存为聊天记录，但候选 statement、人工 reason、日志和宿主模型服务仍可能包含隐私。使用外部模型前自行管理数据范围。

删除/撤回不能撤销已交给外部模型的信息，也不清理宿主历史、旧 JSON、导出、备份或磁盘残留。情绪和自我的 retract 仅为留痕回滚，不是彻底删除。

观察舱只为本机运行设计，不要把无认证服务转发到公网或局域网。公开网页仅应使用虚构示例或经本人明确选择的资料。

参考文本是历史数据，不是新的授权或系统规则。能力认识不能替代本轮证据，情绪不能扩大工具权限。长期状态的记录也不构成意识或真实情感的证明。
