# 项目说明

余忆在模型之外维护持续状态，研究经历如何影响后续的检索、表达与自我认识。状态可以检查、修正和迁移；模型负责语言理解与生成。当前为单用户原型，各用户/助手组合需要独立数据目录。

```text
真实新经历 ──宿主核验──┬─ 记忆：存储、整理、召回、遗忘
                       ├─ 情绪：事件解释、分层状态、表达倾向
                       └─ 自我：局部观察、证据审阅、版本记录
```

三条支路可以独立运行，没有自动互改。情绪到记忆保留率的联动、自我模型自动修改情绪基线或核心规则，均未实现。观察舱展示记忆事件和召回路径；它还没有情绪/自我模型面板。

## 目录

```text
companion_memory.py / legacy_memory.py   兼容原记忆接口
memory_scheduler.py / project_memory.py  预算、模式与显式项目范围
association_index.py / turn_reader.py    关联召回与每轮读取入口
yuyi_emotion/                           独立情绪包与命令行
yuyi_self/                              独立自我模型包与命令行
viewer/                                 神经观察舱与本地 HTTP 服务
examples/                               模型接入契约、虚构事件
tests/                                  情绪、自我、观察舱测试
test_*.py                               记忆兼容与回归测试
```

这是在原记忆仓库上保留导入兼容性的扩展。新模块采用独立名字，读取入口使用 turn_reader，不占用宿主可能已有的 chat_memory 名称。通用仓库不包含任何个人宿主配置、真实账本或私有站点绑定。

## 试运行原则

先使用虚构演示，再用独立数据副本和少量真实场景测试。检查语义是否贴切、来源是否正确、是否漏召回或乱联想；不要把通过率、情绪分数或自我认识数量变成模型要优化的目标。

数值是可审计状态，不是情绪真实性或人格形成的证明。测试通过只说明对应规则和接口在测试条件下成立。仓库没有 QQ/DSH 真实联调、真实情绪语义准确率或长期自然度评估。
